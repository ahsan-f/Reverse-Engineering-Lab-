# Welcome to the REA + VS Code Playground!

In this interactive scenario, you will:
1. Set up Node.js 24 LTS on the Killercoda terminal.
2. Install **REA** (`rea-agents`) and configure it for **VS Code**.
3. Explore the workspace using your AI/agent setup in VS Code.

Click **Start** to launch your environment and open the VS Code editor tab.
